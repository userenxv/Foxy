# Foxy Shaderpack

Foxy is an Iris shaderpack for Minecraft with physically based materials,
volumetric clouds, screen-space and voxel lighting, temporal reconstruction,
water transport, and Voxy/Distant Horizons integration.

## Installation

Copy the shaderpack directory into the Minecraft `shaderpacks` folder and
select it from Iris. The lightweight profile enables block-shaped clouds by
default.
