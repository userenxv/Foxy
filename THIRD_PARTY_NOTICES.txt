   Copyright Contributors to the ACES Project

   License: Apache-2.0
	Used by: shaders/lib/math.glsl (real-time ACES 2.0-compatible display path)
	The tonescale constants are the ACES Core 2.0 presets for 100, 203 and
	1000 nit display peaks. The AP1 primaries, D60 white point, and
	Bradford-adapted Rec.709 conversion matrices are calculated from the same
	ACES Core chromaticities and stored in GLSL column-major order. The compact
	gamut guard is a realtime approximation; the full reference implementation
	uses CAM16/JMh and generated hue-cusp tables, which are not practical in
	this single fullscreen pass at the current performance budget.
